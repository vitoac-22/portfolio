Determinantes Morfológicos y Ontogenia en Dyme ramulus

Author

Víctor Bustos

Resumen de Hallazgos

Este análisis demuestra que la viabilidad del Dyme ramulus no es un evento aleatorio, sino un filtro biomecánico cuantificable:

  1. El diámetro transversal es el guardián de la eclosión: Los huevos exitosos exigen una altura y un ancho significativamente mayores (\(p < 0.001\)). La longitud axial carece de impacto estadístico, desmintiendo que un huevo más grande en todos sus ejes tenga ventaja.
  2. Existe un “corredor alométrico” estricto: Los embriones viables están limitados a una proporción geométrica muy específica entre su ancho y altura (\(R^2 = 0.324\)). Desviarse de esta envolvente física lineal resulta en letalidad.
  3. El punto de quiebre ontogenético es el Instar IV: Una vez superada la eclosión, el desarrollo ninfal muestra una estabilidad promedio, pero el Instar IV exhibe un ensanchamiento crítico en la varianza temporal. Esto marca el momento de mayor vulnerabilidad y dispersión de la población ante el entorno biológico.

Antes de Iniciar: Cuantificando la Intuición Biológica

Cuando observamos el ciclo de vida de un fásmido (insecto palo) como Dyme ramulus, la biología nos dice que el desarrollo embrionario y ninfal enfrenta barreras físicas implacables. Nuestra hipótesis intuitiva es que la forma misma del huevo es el primer gran filtro: su geometría dicta quién sobrevive y quién no.

Aquí, traducimos esa intuición biológica a modelos matemáticos reproducibles. Evaluaremos las dimensiones físicas (ancho, altura, longitud) para descubrir cuál actúa como el verdadero “cuello de botella” biomecánico. A lo largo de este análisis, estructuraremos el pensamiento en tres pilares:

  • Qué hemos hecho: Limpieza y modelamiento espacial de datos morfológicos crudos.
  • Qué suponemos: Que existen restricciones geométricas absolutas (alometría) para que el embrión logre romper el opérculo con éxito.
  • Cómo nos guía la estadística: A través de pruebas robustas (no paramétricas) y modelos de regresión, la estadística nos permitirá separar el simple ruido visual de la verdadera señal de viabilidad biológica.

1. Distribución Morfológica y Superposición

Qué estamos viendo: La vida en sus primeras etapas es sumamente frágil y selectiva, y nuestros datos son un reflejo directo de esa crudeza. Nos enfrentamos a un desbalance de clases profundo: la inmensa mayoría de los huevos simplemente no logra eclosionar.

Si graficamos de forma directa todas las dimensiones físicas (altura \(h\), longitud \(l\), ancho \(w\)) en un plano cartesiano, ocurre un fenómeno visual predecible: los datos de los individuos muertos tapan por completo a los pocos que sí lograron sobrevivir. A este problema técnico se le llama sobretrazado o overplotting.

Para resolverlo y descubrir la verdadera estructura espacial oculta en los datos, aplicamos jitter. Esta técnica introduce una perturbación matemática aleatoria minúscula exclusivamente sobre la clase minoritaria. El resultado separa los puntos visualmente sin alterar la matemática subyacente, revelando dónde se agrupan exactamente los “éxitos” (en azul y rojo) frente al masivo ruido de los fracasos (en gris).

library(dplyr)
library(ggplot2)
library(patchwork)

df <- readRDS("data/processed/fasmidos_clean.rds")

col_pap <- c("No eclosionó" = "#BDBDBD", "Eclosionó" = "#1565C0", "Adulto" = "#C62828")
shp_pap <- c("No eclosionó" = 1, "Eclosionó" = 16, "Adulto" = 17)

crear_cruce <- function(datos, x_var, y_var, x_lab, y_lab, mostrar_leyenda = FALSE) {
  p <- ggplot(datos, aes(x = .data[[x_var]], y = .data[[y_var]], color = estado, shape = estado)) + 
    geom_point(data = filter(datos, estado == "No eclosionó"), alpha = 0.6, size = 1.8) +
    geom_point(data = filter(datos, estado != "No eclosionó"), 
               alpha = 0.85, size = 2.6, 
               position = position_jitter(width = 0.015, height = 0.015, seed = 42)) +
    scale_color_manual(name = "Estado", values = col_pap) +
    scale_shape_manual(name = "Estado", values = shp_pap) +
    theme_bw(base_size = 11) +
    theme(panel.grid.minor = element_blank(), 
          axis.title = element_text(face = "bold"),
          panel.border = element_rect(linewidth = 1)) +
    labs(x = x_lab, y = y_lab)
  
  if (!mostrar_leyenda) p <- p + theme(legend.position = "none")
  return(p)
}

p1 <- crear_cruce(df, "longitud", "altura", "Longitud (l) [mm]", "Altura (h) [mm]", FALSE)
p2 <- crear_cruce(df, "ancho", "altura", "Ancho (w) [mm]", "Altura (h) [mm]", FALSE)
p3 <- crear_cruce(df, "longitud", "ancho", "Longitud (l) [mm]", "Ancho (w) [mm]", TRUE) +
  theme(legend.position = c(0.78, 0.18), 
        legend.background = element_rect(fill = alpha("white", 0.7), color = "grey80"))

(p1 | p2 | p3)

2. Determinantes Transversales de Viabilidad

Qué hemos propuesto y la evidencia estadística: Visualmente ya intuimos que no todas las dimensiones importan por igual, pero en ciencia de datos la intuición no basta; debemos demostrarlo. Aquí, la distribución de las variables no sigue una campana de Gauss perfecta, violando el supuesto de normalidad. Por tanto, la estadística nos exige abandonar pruebas tradicionales como la \(t\) de Student y emplear un enfoque matemático robusto: la prueba de suma de rangos de Wilcoxon (Mann-Whitney \(U\)).

¿Por qué Wilcoxon? A diferencia de las pruebas paramétricas que usan promedios crudos (fácilmente distorsionables por valores atípicos), Wilcoxon ordena todos los datos de menor a mayor y evalúa sus “rangos” o posiciones relativas. Su estadístico determina si los valores de una clase son estocásticamente mayores que los de la otra, mediante la ecuación:

\[U = R_1 - \frac{n_1(n_1+1)}{2}\]

Donde \(R_1\) representa la suma de los rangos de la primera clase y \(n_1\) su tamaño muestral. Esta estructura matemática le otorga inmunidad frente a datos extremos y distribuciones asimétricas.

Los gráficos de violín muestran la densidad de nuestros datos, y la evidencia estadística es contundente:

  • El ancho (\(w\)) y la altura (\(h\)) son los verdaderos parámetros que determinan la viabilidad (\(p < 0.001\)). Vemos claramente que los huevos que logran eclosionar exigen un diámetro transversal mayor.

  • La longitud (\(l\)) es estadísticamente irrelevante. En esta dimensión, el valor \(p\) supera el umbral crítico de \(0.05\). Esto significa que cualquier diferencia observada en la longitud puede atribuirse al simple azar. Un huevo más largo no garantiza éxito, lo que demuestra que el desafío vital del embrión no es longitudinal, sino su capacidad de generar presión sobre su sección transversal para lograr romper el opérculo.

3. Restricción Alométrica Espacial

Modelamiento del espacio y análisis del \(R^2\): Sabiendo de forma concluyente que la sección transversal gobierna la viabilidad, proponemos un modelo de regresión lineal simple para evaluar cómo crecen estas dos variables de forma conjunta (alometría):

\[h = \beta_0 + \beta_1 w + \epsilon\]

Donde \(h\) es la altura, \(w\) el ancho, \(\beta_1\) la tasa de cambio proporcional, y \(\epsilon\) el error no observable.

El coeficiente de determinación (\(R^2\)) nos revela qué porcentaje de la variabilidad de la altura es explicada exclusivamente por el ancho. Es aquí donde la separación de los datos nos cuenta la historia real: si observamos la muestra estratificada en el gráfico (B), notamos que para los individuos que fallan (línea gris), el \(R^2\) es ínfimo (\(0.026\)); sus dimensiones varían casi sin relación alguna. Sin embargo, para los huevos viables (azul y rojo), el \(R^2\) estructural se dispara a \(0.324\), revelando un patrón persistente y no aleatorio.

¿Qué significa esto en la realidad? Nos indica que los embriones exitosos están biológicamente atrapados en una “envolvente física” muy estricta. Sus dimensiones no pueden variar libremente; se ven obligados a mantener una proporción geométrica muy específica para asegurar el espacio biomecánico necesario. Si el crecimiento transversal se desvía de este corredor alométrico lineal, el huevo se vuelve físicamente inviable.

mod_global <- lm(altura ~ ancho, data = df)
label_global <- sprintf("italic(R)^2 == %.3f", summary(mod_global)$r.squared)

df_r2 <- df |>
  group_by(estado) |>
  summarise(r2_val = summary(lm(altura ~ ancho))$r.squared, .groups = 'drop') |>
  mutate(label = sprintf("italic(R)^2 == %.3f", r2_val),
         x_pos = min(df$ancho, na.rm = TRUE),
         y_pos = max(df$altura, na.rm = TRUE) - (row_number() - 1) * 0.06)

4. Varianza Ontogenética Post-Eclosión

Lectura de la dinámica temporal: Una vez que el fásmido logra la hazaña de romper el opérculo y nace, el juego cambia por completo. La biometría restrictiva que gobernaba al huevo pierde protagonismo, cediendo ante las nuevas condiciones de su entorno.

En el gráfico final evaluamos la ontogenia, es decir, el desarrollo ninfal segmentado por estadios o Instars. La línea verde representa el comportamiento promedio (la media) de la duración en días de cada fase. Sin embargo, la verdadera historia biológica se esconde en la varianza: la sombra color salmón representa la desviación estándar de la población.

Al observar la gráfica, notamos un ensanchamiento crítico de esta varianza exactamente en el Instar IV. Esto sugiere que, a nivel estadístico, la población sufre una dispersión masiva en sus tiempos de desarrollo al alcanzar esta etapa. Nos indica una altísima sensibilidad frente a estresores exógenos biológicos, como cambios de temperatura o disponibilidad de alimento, justo antes de volver a estabilizar su ciclo para alcanzar finalmente la adultez.

df_ninfas <- data.frame(
  estadio = factor(
    c("Instar I", "Instar II", "Instar III", "Instar IV", "Instar V", "Instar VI"),
    levels = c("Instar I", "Instar II", "Instar III", "Instar IV", "Instar V", "Instar VI")
  ),
  media_dias = c(24.7, 21.41, 23.1, 21.2, 22.2, 23.2),
  sd = c(1.3, 1.8, 2.5, 6.4, 2.6, 1.4),
  rango_min = c(21, 15, 13, 14, 16, 19),
  rango_max = c(29, 31, 33, 32, 28, 28)
)

df_plot <- df_ninfas |>
  mutate(ymin_sd = media_dias - sd, 
         ymax_sd = media_dias + sd, 
         x_num = as.numeric(estadio))

ggplot(df_plot, aes(x = x_num, y = media_dias)) +
  geom_linerange(aes(ymin = rango_min, ymax = rango_max), color = "grey70", linewidth = 1.5, alpha = 0.6) +
  geom_ribbon(aes(ymin = ymin_sd, ymax = ymax_sd), fill = "#F2E2D2", alpha = 0.8) +
  geom_line(color = "#008B6B", linewidth = 1.2) +
  geom_point(color = "#008B6B", size = 3.5) +
  geom_text(aes(label = round(media_dias, 1)), vjust = -2, color = "#008B6B", fontface = "bold", size = 4) +
  scale_x_continuous(breaks = 1:6, labels = df_plot$estadio) +
  theme_classic(base_size = 12) +

        axis.text.x = element_text(color = "black", margin = margin(t = 5)),
        axis.text.y = element_text(color = "black"),

  labs(x = "Estadio Ninfal", y = "Duración (días)")
